# O&O ShutUp10++ - Toggles for Your Own Windows

O&O ShutUp10++ lists suggested privacy and behavior toggles for the Windows install on this PC. Each line is a change you should read before you apply it. Create a restore point first. It is not a registry cleaner that deletes keys, and it is not a way to hide what a program does. Leave Defender and updates on unless you already understand that one switch.

---

## Why It Stands Out

![O&O ShutUp10++ with Windows toggles on the user's own PC, none applied yet](https://www.ghacks.net/wp-content/uploads/2020/06/oo-shutup-10-privacy.png)

Windows has settings spread across several screens. ShutUp10++ gathers a set of them into a list with a short note on each. The note is the product. A green recommendation is still a change to this computer: some items affect advertising and telemetry, and some can affect store apps, sign-in, or update delivery. Apply one group you have read, reboot, and use the PC. If something you need stops working, undo that group before you touch the next.

Do not turn the whole list on because a screenshot said so. Do not disable antivirus or Windows Update as a bundle to make the PC "clean." Those switches make the machine less safe. ShutUp10++ does not remove malware, and it does not cover tracks. If you are changing a PC that other people use, tell them. Export or note what you changed so you can put it back.

---

## Core Capabilities

- **A Readable List:** Each toggle has a description. Read it.
- **Your Windows:** The changes apply to this install, not to a PC you do not administer.
- **A Restore Point First:** A way back before the first apply.
- **One Group at a Time:** Reboot and test. Undo what broke a feature you need.
- **Security Left On:** Defender and updates stay enabled unless you have a separate, understood reason.

---

## Performance Tips

- Create a restore point and confirm it exists before you apply anything.
- Skip any item whose description you cannot explain.
- Do not use an "apply all" habit from a forum image.
- After a reboot, check that Windows Update still runs.

## Troubleshooting

- An app stopped signing in? Undo the last group you applied. Do not apply more.
- Updates no longer appear? Turn the update-related switch back on and check Windows Update.
- You applied a list from a screenshot? Undo it and start from the descriptions.
- The PC misbehaves and undo is not enough? Use the restore point. This tool is not a malware remover.
